# Assumptions, conventions, and deviations

1. The explicit user instruction is **build without training**. Learning sanity runs, 50-step reconstruction tests, and three-step optimizer reproducibility tests are provided but not executed. Consequently learning effectiveness, benchmark gaps, quantum benefit, calibration quality, collapse after training, training time, and GPU throughput are not established.
2. Only CPU verification was available. CUDA AMP, CUDA deterministic execution, peak GPU memory, and cross-device reproducibility remain to be checked on the user's GPU. Same-seed reproducibility is promised within the same supported software/device setup, not across architectures or library releases.
3. The core supports Python 3.10+ and PyTorch ≥2.3 (required for the selected AMP APIs). Python 3.12.14 and PyTorch 2.8.0 were verified. The Python 3.12 verified pins differ from the broader compatibility ranges; Python 3.10 uses an older compatible PennyLane test oracle. Exact transitive versions from verification are recorded separately.
4. All main variants retain the same detached difficulty head for uncertainty diagnostics. Its supervised loss cannot change the encoder by default. Latent-MVE and advantage-MVE remain independently switchable. The MVE difficulty head's uncertainty of mean cost is not within-start dispersion; normalization benefit must be assessed against batch/instance standardization.
5. Data are single-depot CVRP with positive demand ≤capacity. Nonstandard customer sizes need an explicit capacity. All six supplied fixed datasets use 10,000 instances each, default uniform demands 1–9, and independent split/size seeds. No compute-limited test reduction was used in the supplied data.
6. Environment completion adds the final return-to-depot cost immediately when the last customer is served. Saved rollout sequences otherwise have the start/final depot implicit. Finished rollouts select depot padding with zero incremental cost, entropy, and log-probability. Action validation is enabled for replay and tests; model-generated rollouts rely on masks for speed.
7. Pairwise Euclidean distances use direct `cdist` calculation rather than the matrix-multiplication shortcut, which can produce small positive self-distances. Train costs are continuous Euclidean. kNN allows self/depot attention and selects up to 20 other nearest nodes; decoder feasibility never uses a kNN restriction.
8. Encoder insertion indices are 1-based: q_layer=3 is immediately after the third layer. Encoder/circuits run once per instance before all P starts. Optional quantum edge scoring adds B×N×k directed pair circuits in addition to B×N latent circuits. No dense N×N pair-circuit evaluation occurs.
9. Instance normalization is affine over node positions per embedding channel, with no running statistics. Batch/layer norm are configurable. Distance bias is applied in every encoder attention layer; edge bias is applied only after latent insertion.
10. Latent samples are independent across nodes and shared across starts because the encoder is computed once. Greedy evaluation uses mu; stochastic evaluation sampling can be enabled explicitly. Latent logvar is clamped to [-6,2]; difficulty/critic logvar uses [-10,10] for numerical stability (difficulty bounds are configurable).
11. KL is computed per latent dimension, averaged over instance/node positions, floored by free_bits per dimension, then summed. Beta is annealed over the first 20% of configured epochs/batches, not measured wall time. No latent KL exists when latent MVE is disabled.
12. The classical bottleneck width approximates the 3×n×L trainable circuit parameter count; total counts are measured and recorded. Exact equality is not asserted. The parameter-matched M0 chooses the nearest feasible FFN width; the residual difference is in its config description. There are no disconnected dummy parameters used to inflate counts.
13. Trainable circuit angles use PennyLane's chronological RZ(phi), RY(theta), RZ(omega) convention. Wire 0 is the most significant statevector bit. Ring CNOTs run in ascending control-wire order, including both directed CNOTs at n=2. Final-layer RZ phases can be structurally unobservable under Z/ZZ readout; zero individual gradients do not automatically imply a barren plateau.
14. Complex64 is used even when the independent oracle uses float64. Gate application uses reshape/einsum and permutation indexing without dense 2^n×2^n unitary matrices. Simulator qubit count is bounded at 12 for explicit resource control; requested n=4/6/8/10 settings are supported. Density matrices are only allowed for n≤8 and chunked more conservatively.
15. Depolarization is the local Pauli channel `(1-p)rho + p/3*(XrhoX+YrhoY+ZrhoZ)`, applied independently to each qubit after each entire layer's entangling ring. It is not the alternate `(1-p)rho+p*I/2` convention. Finite-shot sampling approximates independent observable marginals and does not reproduce Z/ZZ measurement covariance. Noise is inference-only. Robustness for the optional edge variant currently perturbs the latent circuit; edge-circuit noise is not modeled.
16. Reconstruction targets are detached LayerNorm(x) at the insertion point. The head reads z directly, so its loss need not train circuit angles. With recon off, the component is named latent bottleneck. With recon and latent MVE on, it is variational latent autoencoder; deterministic reconstruction-only variants are called latent autoencoder.
17. A fixed-zero gate is an exact forward no-op, but separately enabled auxiliary KL/reconstruction losses can still affect the shared encoder. Gate-zero is therefore an output-path ablation, not equivalent to removing all auxiliary objectives. Signed alpha<0.02 triggers the requested heuristic report; negative large-magnitude alpha warrants inspection rather than automatic interpretation as bypass.
18. Train augmentation selects one of eight symmetries randomly per batch, preserving nominal batch size. Inference x8 evaluates all eight. Sampling S means S stochastic POMO passes (P=m starts each), not S single-start tours. Candidate counts are explicitly reported.
19. PPO is clipped episodic actor-critic with gamma=1, terminal negative full-tour cost, Monte Carlo targets, and a shared-encoder 1D-conv critic reading last-node/load context. It does not implement GAE or minibatching of trajectory steps; K=3 whole-batch replays are the default. Latent eps is fixed across old/new likelihood computation. The critic can influence the encoder. MVE critic NLL begins after MSE warm-up; disabling MVE uses a scalar MSE critic.
20. The first customer visit in every POMO rollout is forced and excluded from policy likelihood. With P=1 REINFORCE's shared baseline makes the advantage zero; research runs use P=m. The default decoder uses the specified global/last-node/load context and C=10 clipping; no extra first-node context was introduced.
21. PyVRP 0.12.2 HGS solves integer edges after scale=1e6 quantization, with up to m vehicles. Cached reference costs re-score the feasible routes in continuous Euclidean units. Caches are heuristic feasible references; they do not certify optimality. Runtime-limited HGS is not guaranteed bitwise reproducible even with its seed fixed; storing the actual cache provides reproducible comparisons.
22. Reference caches store solver version, per-instance time limit, seed, quantization, dataset fingerprint, objective, and source. Full reference sets were not solved during construction. Tiny HGS instances were solved only as adapter tests. Importing published costs assumes the user has established correspondence with the exact saved instances and cost convention.
23. CVRPLIB input is restricted to single-depot CVRP with coordinates. Isotropic scaling uses the largest coordinate range so raw Euclidean geometry can be recovered by one scale factor. It intentionally avoids independent per-axis scaling. Nearest integer is floor(d+0.5). Original order, offset, scale, raw coordinates, edge-weight type, and comparison rounding are retained. Best-known .sol conventions must match the comparison convention; both raw continuous and nearest-rounded candidate costs are reported.
24. CVRPLIB model decisions encode normalized Euclidean geometry; candidate selection and reporting can use rounded or supplied explicit edge objectives. The loader does not implement a model for arbitrary nongeometric graphs. Best-known solution provenance comes from user-supplied local .sol files. No CVRPLIB downloads or known costs are fabricated.
25. Difficulty calibration uses mean costs across P starts (and averaged augmentation/sampling passes), measured in normalized training geometry units. Spearman analyses compare uncertainty to realised selected-route gaps. Absent or constant uncertainty yields unavailable correlations instead of invented values. Shifted distributions must receive newly computed matching reference caches.
26. Paper summary standard deviations are across seed-level metrics. Paired Wilcoxon comparisons average costs over matched seeds for each instance, then pair instances, avoiding treating correlated seed-instance pairs as independent. This supports instance-distribution inference; it is not a standalone test over training seeds. Holm correction spans all comparisons in one report invocation. Exact reference arrays and instance IDs are checked.
27. Best checkpoint selection uses validation cost, not gap, which is equivalent for selecting lower mean length but can differ from selecting mean relative gap across varying references. All loss/gradient diagnostics are pre-clipping measurements. Quantum parameter counts include frozen angles; trainable counts are separated.
28. Time budgets are checked between batches and include validation; they may overrun by a batch or validation. Checkpoints are epoch-granular. Resume requires unchanged config and fixed validation/reference contents; unsaved partial epochs are recomputed. An exhausted saved time budget must not silently be extended.
29. Epoch/inference timings are real measurements of the executing machine, never placeholders. One-state memory estimates exclude autograd history/gate temporaries; CUDA peak allocation is measured separately. Initial-gradient sweeps perform backward passes without optimizer steps. During-training sweeps require actual trained run logs for each architecture.
30. Optional IBM/Aer/fake hardware checks are isolated and not part of the required dependency graph. IBM jobs require an explicit backend selection and saved account. Hardware execution and Qiskit adapters were not exercised here. Generic fake-backend noise is not claimed equivalent to the local layer depolarization model.
31. Optional reproduction of an unidentified base paper's GAT/Q-GAT is not included: no paper citation, exact graph architecture, or reproduction hyperparameters were supplied. POMO/quantum/PPO variants are implemented in the common evaluation pipeline. This avoids labeling a guessed implementation as a paper reproduction.
32. No research benefit is presupposed. Reports retain negative improvements, non-significant p-values, unavailable references, and collapse flags. Untrained forward costs in verification logs are plumbing checks, not research results. All optimizer-update tests remain opt-in.
