2. ENVIRONMENT (batched, vectorised, supports POMO multi-start)
------------------------------------------------------------
- Shape convention: (B instances, P parallel rollouts/starts, ...).
- State: static coords/demands; dynamic remaining load, current node, visited mask.
- Masking: visited customers; customers with demand > remaining load; depot masked when
  at depot (no depot-to-depot) unless all customers are served. Episode ends when all
  customers are served; finishing rollouts are padded safely.
- Cost = total euclidean length including return to depot. Reward = -cost.
- Multi-start: P = m rollouts, rollout p starts by visiting customer p first.
- 8-fold symmetry augmentation of coordinates (x,y)->(x,1-y),(1-x,y),(y,x), etc.
  Demands unchanged. Applicable at train (optional flag) and inference.
- Tests: no capacity violation; every customer exactly once; cost equals brute-force
  recomputation; augmentation preserves optimal cost (check on tiny instances vs
  brute force / PyVRP).

3. MODEL (every module switchable by config)
------------------------------------------------------------
a) Input embedding: Linear for customers, separate Linear for depot, d_model=128.
b) Encoder: 6 Transformer layers (8 heads, FFN 512, instance/batch norm as in POMO),
   attention logits += learned bias from pairwise distance
   (bias = MLP(distance) per head, or a learned scalar times -distance; config flag).
   The encoder runs ONCE per instance (not per start), so the quantum block cost is
   B*N circuits per forward pass.
c) Latent Bottleneck / Quantum Latent Block, inserted after encoder layer `q_layer`
   (default 3), parallel to the main path:
   - LayerNorm -> Linear(d_model -> d_lat), with d_lat = n_qubits (default 6).
   - MVE latent head: Linear -> (mu, logvar), logvar clamped to [-6, 2].
     Train: z = mu + exp(0.5*logvar)*eps. Eval-greedy: z = mu.
     Eval-sampling: configurable. Flag mve_latent on/off.
   - Angle map: theta = pi * tanh(z).
   - VQC (own batched statevector simulator, state tensor (B*N, 2^n), complex64):
     * data re-uploading: RY(theta_i) on each qubit, repeated at each of L layers
       (default L=2);
     * trainable Rot(phi, theta, omega) per qubit per layer;
     * ring CNOT entanglement per layer;
     * outputs <Z_i> for all qubits, plus optional <Z_i Z_{i+1}> (flag);
     * gates applied via reshape + einsum on the statevector (never build 2^n x 2^n
       matrices); autograd for gradients (no parameter-shift needed);
     * init trainable angles N(0, 0.1).
   - Backends (switch): 'quantum', 'classical_bottleneck' (same d_lat in/out dims,
     small MLP with a comparable parameter count, tanh activations),
     'frozen_random_quantum', 'none' (block removed).
   - Latent decoder: Linear(n_out -> d_model).
   - Gated residual: x' = x + alpha * dec(q), alpha a learnable scalar init 0.1.
     Flag to fix alpha at 0 (ablation). Log alpha.
   - Optional noise models for robustness tests (inference only):
     finite-shot sampling (binomial/Gaussian approximation of expectation values) and
     depolarizing channel via density-matrix path (only n_qubits <= 8).
   - Remaining encoder layers run on x'.
   - Optional auxiliary reconstruction head (flag recon_loss, default OFF):
     MLP(d_lat -> d_model) on z (sampled in train, mu in eval), target = detached
     LayerNorm(x). Weight lambda_rec (default 0.01).
   - Optional variant `quantum_edge_scoring` (off by default): for the k nearest
     neighbours only (N*k pairs), encode [z_i, z_j, d_ij] into a small circuit and use the
     expectation output as an additive attention-logit bias in later layers. Implement
     only after everything else is tested.
d) Global embedding: concat(mean(H), max(H)) over customer nodes.
e) Decoder (POMO-style): multi-head attention context from
   [global embedding, last-node embedding, remaining load]; single-head logits clipped
   with C*tanh (C=10); masking with -inf; softmax. Greedy, sampling with temperature.
f) MVE difficulty head: small MLP on global embedding -> (mu_c, logvar_c) predicting the
   mean cost across starts for that instance (heteroscedastic instance difficulty).
   Gradients into the encoder are blocked by default (detach flag, so the head cannot
   distort the representation); config flag to allow them.

------------------------------------------------------------
4. TRAINING
------------------------------------------------------------
Algorithm switch: `pomo_reinforce` (default) and `ppo` (ablation).

POMO REINFORCE:
- Per instance, P rollouts; reward R = -cost.
- Shared baseline b = mean of R over the P rollouts of the same instance.
- Advantage A = R - b. Advantage-normalisation modes (config, all ablated):
  1. none,
  2. batch std,
  3. within-instance std across rollouts,
  4. MVE: A / (sigma_c + eps), clamped to a sane range, where sigma_c = exp(0.5*logvar_c),
     detached. NOTE: sigma_c is uncertainty of the instance mean cost, while A is
     within-instance spread; these differ, so mode 4 must be judged empirically
     against modes 2 and 3 and reported honestly if it does not help.
- Loss_policy = -mean(A_normalised * logprob_sum).
- MVE difficulty head loss: Gaussian NLL on the instance mean cost; first few epochs use
  MSE warm-up, then NLL.
- Latent KL: beta * KL(q(z|x) || N(0, I)) with free-bits per dimension; beta annealed
  linearly 0 -> beta_max (default 1e-3) over the first 20% of training.
- Reconstruction (only if recon_loss on): + lambda_rec * MSE(recon, target), logged
  as a separate term.
- Total: policy + lambda_c * difficulty_loss + beta * KL (+ lambda_rec * recon).

PPO ablation (paper-style): actor-critic with a critic reading the shared encoder through
a 1D-conv head; critic MVE head (mu_v, logvar_v) with MSE warm-up then Gaussian NLL
(flag mve_critic); clip 0.2, K=3 update epochs, entropy 0.01, gradient clip 1.0.

Common: Adam lr 1e-4 (configurable decay), batch size configurable (default 64 for m=100,
128 for m=50, 256 for m=20), epochs/steps configurable (default 100 epochs, state clearly
that POMO-quality results typically need far longer; provide `--epochs` and a
time-budget mode). Seed everything. Checkpoint best-by-validation. Support `--seed`.

Logging each epoch: mean cost, gap on validation, every loss term, gradient norm of
quantum parameters (separately from classical), epoch time, parameter counts split
classical vs quantum vs total, and LATENT DIAGNOSTICS: KL per latent dimension, number of
active dimensions (KL > 0.01), mean latent sigma, alpha, fraction of node-embedding norm
contributed by alpha*dec(q), and reconstruction error when recon is on.

Collapse report: after training, write a short report flagging alpha < 0.02, active
dimensions <= 2, or mean latent sigma > 0.9 as possible bypass or collapse.
